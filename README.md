# 赤飯・もち算出計算機

添付のExcelファイル（赤飯／もちシート、商品一覧シート、原材料算出シート）の算出ロジックを
そのまま移植した、ビルド不要の静的PWA（Progressive Web App）です。

ビルドツールやフレームワークは使わず、素の HTML / CSS / JavaScript（ESモジュール）だけで
構成しているので、Node.js のインストールも不要で動かせます（開発時の簡易サーバー起動にのみ
Python か Node があると便利、という程度です）。

## 機能

- **赤飯タブ**：商品と数量を入力すると、出来上がり必要量・必要なもち米の量・ささげの量・
  せいろ数・1せいろあたりの分量を自動計算（元シート「赤飯」を移植）
- **もちタブ**：白もち系・粟もち系それぞれの商品と数量、あわ／もち比率を入力すると、
  必要もち米量・必要あわ量・せいろ数を自動計算（元シート「もち」を移植）
- **原材料算出タブ**：もち米の量(kg)を入力すると、赤い水・水・塩・ささげの分量を自動計算
  （元シート「原材料算出」を移植）
- **商品一覧タブ**：商品名と内容量(g)のマスタを追加・編集・削除可能（元シート「商品一覧」を
  移植。VLOOKUPの参照元だったテーブルを、赤飯用／もち用／粟もち用の3系統で管理）
- 入力内容・商品マスタはすべて端末の `localStorage` に自動保存されます（サーバー通信なし）
- Service Worker によりオフラインでも起動・利用可能
- 「ホーム画面に追加」でアプリのようにインストール可能（PWA）

計算式はすべて `js/calc.js` に集約し、元Excelから抽出した実測値との一致を
`tests/calc.test.mjs` で検証済みです（下記「計算ロジックの検証」参照）。

## 環境構築（ローカルで試す）

このアプリはビルド不要の静的ファイルです。Service Worker はセキュリティ上の理由で
`file://` では動作しないため、ローカルでも簡易的な HTTP サーバー経由で開いてください。
（`localhost` は特別扱いされるので、HTTPS化は不要です。）

どちらか使える方でOKです。

```bash
# Python3 がある場合
cd ricecake_calculator
python3 -m http.server 8080

# Node.js がある場合
cd ricecake_calculator
npx serve . -l 8080
```

起動後、ブラウザで `http://localhost:8080/index.html` を開いてください。
スマートフォンから試す場合はPCと同じWi-Fiに繋いで `http://<PCのIPアドレス>:8080/` へ。

Chrome/Edge の場合、アドレスバーの「インストール」アイコン、または画面右上の
「ホーム画面に追加」ボタンからアプリとしてインストールできます。

## 本番公開（実際にPWAとしてインストールして使う場合）

Service Worker と「ホーム画面に追加」を実運用でも使うには、HTTPS配信が必要です
（`localhost` 以外）。ビルド不要な静的ファイル一式なので、以下のような無料の
静的ホスティングにそのままアップロードするだけで公開できます。

- GitHub Pages（このリポジトリの `Settings > Pages` でこのブランチ/フォルダを指定）
- Netlify / Vercel（リポジトリを接続するだけ、ビルドコマンドは空でOK）
- Firebase Hosting（`firebase deploy`）

どれもリポジトリ直下（`index.html` のある階層）をそのまま公開すれば動作します。

## 計算ロジックの検証

`js/calc.js` の計算関数は、添付Excelから実測した値と一致するように実装・検証しています。

```bash
node tests/calc.test.mjs
```

赤飯・もち・原材料算出それぞれについて、Excel側の実測値（例：赤飯＝お赤飯通常パック20個
＋230gパック42個 → 出来上がり必要量15.66kg／必要もち米8.243kg／ささげ577g／せいろ数3）と
完全一致することを確認済みです。

## ディレクトリ構成

```
index.html            画面のエントリポイント（タブ構造）
css/style.css          スタイル
js/round.js             Excel の ROUND / ROUNDUP を再現する丸め関数
js/calc.js               赤飯・もち・原材料算出の計算ロジック本体
js/data.js               商品一覧のデフォルトデータ（Excel「商品一覧」シート移植）
js/store.js              localStorage への保存・読み込み
js/ui.js                  画面描画（タブごとのDOM構築）
js/dom.js                 DOM生成の小さなヘルパー
js/app.js                 起動処理・タブ切り替え・Service Worker登録
js/install.js             「ホーム画面に追加」ボタンの制御
manifest.webmanifest    PWAマニフェスト
sw.js                    Service Worker（オフラインキャッシュ）
icons/                  アプリアイコン
tests/calc.test.mjs      計算ロジックの検証テスト
```

## 元Excelとの対応・注意点

- せいろ数などの丸め方は Excel の `ROUND` / `ROUNDUP` の挙動（0から離れる方向への丸め）を
  忠実に再現しています。
- 「もち」シートの粟もちの出来上がり必要量（元シートの `F12` セル）は、Excel側の数式が
  `G3・G4・G5・G8` を参照しており、実際に商品が定義されている行（粟もち2升・1升・6切）と
  ずれがありましたが、本アプリでは粟もち用に登録された商品すべてを正しく合計するように
  修正しています（結果として空欄参照だった分は元々0扱いだったため、通常のデータでは
  計算結果に影響ありません）。
- あわ／もち比率（元シートの `H12=0.8`, `I12=1`）は「もち」タブ内で自由に変更できるように
  UI化しています。
